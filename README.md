## About this project

### Summary

A self-hosted infrastructure lab with VPN-gated services, internal DNS, firewalls, and containerized applications.

### Skills

- GNU/Linux system administration using SSH
- Docker service management using tools such as Docker and Docker Compose
- Firewall configuration to filter, allow, and deny network traffic across a Virtual Private Server (VPS)
- VPN configuration to simulate a work environment
- Securely exposing services to the Internet and internal network
